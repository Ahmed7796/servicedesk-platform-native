## Decisions made
- A missing requester or actor user throws (so 500) and is logged by the framework, instead of inventing a name. It cannot happen: `FK_AuditLogs_Users_ActorId` and `FK_ServiceRequests_Users_RequesterId` are Restrict. The throw guards an impossible state. Alternative considered: a placeholder name, rejected as false data against a contract that requires a real `actorName`.
- Sort by `Sequence` alone (not `OccurredAt` then `Sequence`), as agreed.
- The test shuffles the entity's private `_auditLogs` list by reflection, since the repository returns the entity and the domain keeps the list private. Alternative: a test-only setter, rejected to avoid changing the domain.

## Java to C# notes
- `record AuditEntryDto(...)` is like a Java record / Lombok `@Value` DTO; the difference is that leaving `Sequence` out of the positional constructor is what keeps it out of the JSON, with no `@JsonIgnore` needed.
- `RequestStatus?` is a nullable enum, like a boxed field that may be null in a Java DTO; it serializes as JSON `null` (key kept), which the contract requires for `statusBefore`.
- `OrderBy(a => a.Sequence).Select(...).ToList()` is the same as `stream().sorted(Comparator.comparingInt(...)).map(...).toList()`.
- `string NameOf(Guid id) => ...` inside a method is a local function. Java lambdas also capture effectively final locals; the real differences are that it is a named method, it can be called before its declaration, it can recurse, and it can capture and modify non-final locals.
- `names.TryGetValue(userId, out var name)` is like `Map.get` with a null check in one call; `out var` declares the result variable inline.
- `ToDictionary(u => u.Id, u => u.DisplayName)` is like `Collectors.toMap(User::getId, User::getDisplayName)`.
- Reflection in tests (`GetField("_auditLogs", BindingFlags.NonPublic | BindingFlags.Instance)`) is like `ReflectionTestUtils.getField` in Spring Test, used only to put the private list in a shuffled order.
