# Hand-off: M5-2 End-to-end script through the proxy

**Agent:** lead  **Date:** 2026-11-19

## What changed
- `scripts/e2e.py` (new; standard library only) runs the demo flow through the reverse proxy, as the phone would:
  1. the proxy is up;
  2. the four demo accounts sign in through `/api`;
  3. the requester submits an Equipment request;
  4. the copilot posts a triage suggestion, and the request is still `Submitted` (rule 6);
  5. `ops.head` finds it in `pending-for-me` and approves the DepartmentHead step;
  6. `it.manager` does the same for the ItManager step;
  7. the status is `Approved`;
  8. the admin fulfils it, and the status is `Fulfilled`;
  9. the audit trail is `Submitted > StepApproved > StepApproved > Fulfilled`, oldest first;
  10. notify no longer lists it in `/notify/overdue`.
- Options: `--base-url`, default `http://localhost:8000` or `E2E_BASE_URL`, and `--triage-timeout`, default 120 s. The demo password comes from `DEMO_PASSWORD`, defaulting to the Development seed's.
- The script exits 1 on the first failed step and prints that step. No dependency, nothing to install.

## How it was verified
- **The tree tested:** a local branch merging `main`, this branch (on top of #49, the proxy) and #52 (canned mode). It was never pushed, and it has been deleted.
- **Run:** `docker compose down -v`, then `COPILOT_MODE=canned GEMINI_API_KEY= docker compose up --build`. All eight services were healthy.
- **Result:** `python3 scripts/e2e.py` printed **E2E passed** with all ten steps ok. The triage was Equipment / High, routed DepartmentHead then ItManager.
- **Acceptance check from PLAN.md ("Script passes against a fresh `docker compose up --build`"): pass.** This was in canned mode.
- **Two script bugs, found on the first runs and fixed:**
  - The script parsed every response as JSON, but `/proxy-health` returns plain text.
  - It expected a separate `Approved` audit entry. The API records the last approval as `StepApproved`, like the first.

## Decisions made
- **Through the proxy, not straight to the api:** M5 is about the phone's single address.
- **Canned mode for the recorded run:** Gemini returned 503 and 504 for most of 2026-11-19. In llm mode the script works the same way, as long as Gemini answers within `--triage-timeout`.
- **Standard library only:** a reviewer can run it with any Python 3.10+.

## Review this hardest
