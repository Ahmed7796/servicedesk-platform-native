## Decisions made
- Full JSON Schema fields (`response_json_schema`, `parameters_json_schema`) rather than the OpenAPI-subset `response_schema`, because the pydantic schema is JSON Schema. Alternative: convert to `types.Schema`.
- Non-retryable `APIError` (400/401/403/404) propagates unchanged and the agent reports the class name only. A blocked or empty final answer is a plain `ValueError`, not retried.
- `build_llm` lives in `gemini.py` (approved); M3-3c calls it in the lifespan.
- Tool results go back as `function_response` `{"result": "<wrapped data text>"}`; Gemini calls have no ids, so matching is by name and order.

## Review this hardest
- Error mapping in `gemini.py::_generate`: `from None` (no cause chain, message is the status code only), and that only `Exception` is caught so `CancelledError` (the agent's timeouts depend on it) passes through. `_is_transport_error` is broad on purpose (any `httpx`/`httpx2`/`aiohttp` class, any `OSError`), so a non-transient transport bug such as a bad URL would also be retried.
- `sanitize_schema`: that it only drops keywords and never loosens `required`, enums or constraints it keeps; that it does not touch property names; the cycle guard.
