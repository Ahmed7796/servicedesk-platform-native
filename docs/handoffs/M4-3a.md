## Decisions made
- **Intl on Hermes.** The android export only bundles; it does not run JavaScript, and no Hermes VM is available here, so I could not confirm that `Intl.RelativeTimeFormat` exists in RN 0.88 on a device. `formatAge` therefore checks for it at call time and falls back to an absolute date ("Nov 16, 2026") when it is missing. Both paths are tested in Node (jest), which has full Intl. Check the age text on a real device or emulator.
- The hook returns a plain error string, 401 is not special-cased: M4-2b's interceptor clears the token and resets to Login.
- Empty state text is "Nothing is waiting for your decision." so an Admin's usually empty list reads fine.
- `ListEmptyComponent` renders only after a successful load, so an error on first load shows the error text and no "nothing waiting" claim.

## Review this hardest
- `usePendingApprovals`: `alive` stops updates after unmount; `latest` (request counter) lets only the newest request update state or clear the spinner. The overlap test needs three calls (load, slow refresh, fast refresh) because the list, and so the pull-to-refresh control, is not rendered during the first load.
- Row text joins several fields with " · " in one `Text`; long titles or names wrap, they are not truncated.
- Hermes `Intl.DateTimeFormat` options `{year, month, day}` in the fallback path are untested on a device.
